## 日常作業速覽

> 最常用流程:**主控台輸入車牌 → 點車輛卡片進入「維修檔案頁」→ 建立維修紀錄 / 列印估價單**。

- 找不到車輛時,搜尋結果可直接「建立車輛」並進入該車檔案頁。
- 點任何**維修紀錄、客戶、車輛**一律先進入**檢視頁**(唯讀),檢視頁右上角再按「編輯」修改。
- 手機操作可直接開啟相機拍照;照片上傳時自動壓縮。
