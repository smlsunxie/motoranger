# 01 入門

## 1.1 登入系統

開啟瀏覽器進入 **<https://main.motoranger.net/admin>**(本地開發為 `http://127.0.0.1:8088/admin`),輸入 E-Mail 與密碼後按「登入」。

![登入頁](images/login.png)

> 帳號由管理員在「員工」功能中建立;忘記密碼請聯絡系統管理員重設。

## 1.2 介面導覽

登入後進入系統主畫面:

![系統主畫面](images/dashboard.png)

- **左側選單**:維修單、零件、客戶、車輛、廠牌、店家、店家支出、員工,點擊即切換功能。
- **頂部搜尋(全域搜尋)**:可直接輸入 **客戶姓名、手機、車牌、維修單號**,快速跳到對應資料。
- **右上角頭像**:登出系統。
- 側欄可收合,手機與平板亦可操作(響應式介面)。

## 1.3 角色權限

| 角色 | 說明 |
|---|---|
| 管理員 (admin) | 全部功能,含員工帳號管理 |
| 一般員工 (user) | 日常維修、客戶、零件作業 |
